# The Warm Lantern

A responsive, cinematic Malaysian Choose Your Own Adventure for readers aged 10–12. Aman, Kumar and Mei Lin discover a tunnel beneath Sekolah Kebangsaan Bukit Cempaka and follow its evidence into four distinct endings.

## Experience

- Consequential branching story with The Discovery, The Guardian, The Hidden Classroom and The Escape
- Nine discoverable clues with larger evidence views and open questions
- Progressive hand-drawn cave map and post-ending branching map
- Adventure Journey Report, non-judgemental player profile and optional reflection
- Four-lantern ending collection with a Master Explorer unlock
- Local autosave, backtracking, optional quiet ambience and captioned story sounds
- Keyboard focus states, reduced-motion support, touch-friendly controls and responsive layouts

The implementation follows the supplied `THE WARM LANTERN.md` manuscript and `BUILD PROMPT.md` specification.

## Run locally

